# 🌷 婉欣的学习打卡工作台

单文件网页（`index.html`），纯前端、无外部依赖、无后端，数据存浏览器 `localStorage`。iPhone / iPad Safari 适配，可「添加到主屏幕」当 App 用。

## ⏰ 日程页（默认打开）

左栏第一个就是「⏰ 日程」，把每天的时间段做成一条时间轴，当前时段会高亮：

| 时间 | 内容 | AI |
|---|---|---|
| 16:30–17:00 | 放学回家 · 点心放松 | 推送今日任务清单、预览 |
| 17:00–17:25 | 语文 · 控笔+每日写字 | 笔画示范旁白 + 25 分钟计时 |
| 17:25–17:35 | 休息拉伸 | 提醒起来走动 |
| 17:35–18:00 | 语文 · 拼音+课后习题 | 朗读拼音/题目 |
| 18:00–18:30 | 晚餐 | 暂停任务 |
| 18:30–18:55 | 数学 · 口算+数字+课后+校信 | 随机口算报题 |
| 18:55–19:05 | 短暂休息 | 提醒休息 |
| 19:05–19:30 | 英语 · 字母+自然拼读+绘本 | 拼读/绘本示范朗读 |
| 19:30–19:55 | 钢琴 · 指法+曲谱+打卡 | 节拍器（120） |
| 19:55–20:15 | 古诗背诵 + 思维训练 | 朗读古诗、引导题 |
| 20:15–20:30 | 运动 + 洗漱 | 计时；20:20 预警 |
| 20:30 | 全部结束 | 收工 |

- 每个时段有：**🔊 听提示**（语音播报该段提示 + 对应内容）、**▶ 计时**（到点提醒）、钢琴段额外有 **🎹 节拍器**。
- 时段里的任务可以直接勾选，和左栏分类、总进度**实时同步**。
- 顶部有 **🔊 播报今日完整任务清单**。
- 当前时段变化会推送“进入：…”提醒；时间紧可压缩带「🌿可减量」的任务。

## 布局：左侧栏分类导航

左栏是整个工作台的导航（可上下滚动），点一个就切换右边内容：
**📖语文 · ➗数学 · 🇬🇧英语 · 🎹钢琴 · 🏃运动 · 🪥习惯 · 🐱宠物 · 🧾记录 · 👪家长 · ⚙️设置**。
每个分类项后面会显示小进度（如 4/6）。

## 怎么用

1. **打开**：把 `index.html` 传到手机上（或部署成网址），用 **Safari** 打开。
2. **添加到主屏幕（像 App）**：Safari 里点底部「分享」→「添加到主屏幕」→ 命名「学习打卡」。之后从主屏图标打开，全屏无地址栏。
3. **打卡**：点任务左边的方框，打勾即自动保存（刷新不丢）。再点一下取消勾选。
4. **朗读**：任务右侧有 🔊 朗读按钮——
   - 古诗背诵 → 朗读古诗（**按部编版一年级上册**：咏鹅、江南、画、悯农其二、古朗月行、风，会轮流换诗，再点一次停止）
   - 拼音练习 → 朗读声母/韵母/整体认读/拼读
   - 每日口算 → 随机出题并语音报题（**只报题，不给答案**）
   - 自然拼读 → 英语字母 + 单词示范发音
5. **宠物**：完成得积分 → 攒够升级；用「可用积分」喂食/玩耍/买配饰。
6. **家长查看 · 本周报告**：点「📊 查看本周报告」展开——本周打卡天数、平均完成率、本周获得积分、20:30 前完成天数、全勤天数、连续全勤，以及各科本周完成率和每日明细（含复盘）。
7. **音效**：每次打卡都有**马里奥吃金币声**（纯本地 WebAudio，无音频文件）；右上角 🔔/🔕 可开关。
8. **今日复盘**：底部输入框，自动保存，跨天会存进历史。
9. **重置今日**：清空今天的打卡，**保留**历史记录、积分、宠物。
10. **备份**：底部「导出备份 / 恢复备份」，换手机或清缓存前先导出。

## 积分规则

- 每完成 1 项任务：**+5 分**
- 当天 21 项全部完成：额外 **+10 分**
- **取消打卡：扣回对应积分**（-5；若因此不再全完成，全勤 +10 也一并收回）
- **总积分（累计）**：决定宠物等级（取消打卡会相应减少）
- **可用积分**：用来喂宠物/买配饰（消费不影响等级）

### 宠物等级（按总积分）
| 总积分 | 等级 |
|---|---|
| 0–99 | 🥚 宠物蛋 |
| 100–299 | 🐱 幼崽 |
| 300–599 | 😺 成长中 |
| 600+ | 😻 成年宠物 |

### 宠物消费（扣「可用积分」）
- 5 分：🍚 喂食，开心值 +1
- 10 分：🎾 玩耍，开心值 +2
- 15 分：🎀 买配饰

## 时间规则

- 16:30 开始 / 20:20 收尾预警 / 20:30 停止做题 / **20:40 后不能再打卡**（页面会按当前时间高亮对应那条，并显示提示条）。
- 过了 20:40，勾选与「一键全打勾」都会被阻止（提示“今天不能再打卡了”）；查看、宠物、重置而不受限制。

## 其他说明

- 数据只在本机浏览器，**不上传联网**。
- iPhone 与 **iPad** 都适配（iPad 下字号、行高、左栏会自动放大）。
- 语音用浏览器自带 Web Speech API（Safari 原生），不需要联网接口。若没声音，检查手机侧边**静音开关**是否关掉（iOS 静音会屏蔽朗读）。
- 换域名/清 Safari 数据会导致数据丢失，重要进度先「导出备份」。
