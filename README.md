# 🌷 婉欣的学习打卡工作台

单文件网页（`index.html`），纯前端、无外部依赖、无后端，数据存浏览器 `localStorage`。iPhone Safari 适配，可「添加到主屏幕」当 App 用。

## 怎么用

1. **打开**：把 `index.html` 传到手机上（或部署成网址），用 **Safari** 打开。
2. **添加到主屏幕（像 App）**：Safari 里点底部「分享」→「添加到主屏幕」→ 命名「学习打卡」。之后从主屏图标打开，全屏无地址栏。
3. **打卡**：点任务左边的方框，打勾即自动保存（刷新不丢）。再点一下取消勾选。
4. **朗读**：任务右侧有 🔊 朗读按钮——
   - 古诗背诵 → 朗读古诗（**按部编版一年级上册**：咏鹅、江南、画、悯农其二、古朗月行、风，会轮流换诗，再点一次停止）
   - 拼音练习 → 朗读声母/韵母/整体认读/拼读
   - 每日口算 → 随机出题并语音报题（**只报题，不给答案**）
   - 自然拼读 → 英语字母 + 单词示范发音
5. **宠物**：完成得积分 → 攒够升级；用「可用积分」喂食/玩耍/买配饰。
6. **家长查看 · 本周报告**：点「📊 查看本周报告」展开——本周打卡天数、平均完成率、本周获得积分、20:30 前完成天数、全勤天数、连续全勤，以及各科本周完成率和每日明细（含复盘）。
7. **音效**：每次打卡都有**马里奥吃金币声**（纯本地 WebAudio，无音频文件）；右上角 🔔/🔕 可开关。
8. **今日复盘**：底部输入框，自动保存，跨天会存进历史。
9. **重置今日**：清空今天的打卡，**保留**历史记录、积分、宠物。
10. **备份**：底部「导出备份 / 恢复备份」，换手机或清缓存前先导出。

## 积分规则

- 每完成 1 项任务：**+5 分**
- 当天 21 项全部完成：额外 **+10 分**
- **总积分（累计）**：只增不减，决定宠物等级
- **可用积分**：用来喂宠物/买配饰（消费不影响等级）

### 宠物等级（按总积分）
| 总积分 | 等级 |
|---|---|
| 0–99 | 🥚 宠物蛋 |
| 100–299 | 🐱 幼崽 |
| 300–599 | 😺 成长中 |
| 600+ | 😻 成年宠物 |

### 宠物消费（扣「可用积分」）
- 50 分：🍚 喂食，开心值 +1
- 100 分：🎾 玩耍，开心值 +2
- 150 分：🎀 买配饰

## 其他说明

- 时间提醒：16:30 开始 / 20:20 收尾预警 / 20:30 停止做题——页面会按当前时间高亮对应那条。
- 数据只在本机浏览器，**不上传联网**。
- 语音用浏览器自带 Web Speech API（Safari 原生），不需要联网接口。若没声音，检查手机侧边**静音开关**是否关掉（iOS 静音会屏蔽朗读）。
- 换域名/清 Safari 数据会导致数据丢失，重要进度先「导出备份」。
